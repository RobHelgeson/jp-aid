# Story 2.1: Text Parsing

**Status:** Done

**Story**
As a user, I want the system to correctly identify and extract only the unique kanji characters from my input, so that I can focus on the kanji present in any word or sentence.

**Acceptance Criteria (ACs)**

1. The system accepts any Japanese text input (word, sentence, phrase).
2. Only kanji characters are extracted; kana, punctuation, and duplicates are ignored.
3. Extraction is accurate for mixed-content input (kanji, kana, Latin, symbols).
4. The extracted kanji are passed to the next processing step.

* **Kanji Character Detection**:
  * **Unicode Range**: Kanji characters fall within these Unicode ranges:
    * CJK Unified Ideographs: `\u4E00-\u9FFF` (common kanji)
    * CJK Unified Ideographs Extension A: `\u3400-\u4DBF` (rare kanji)
    * CJK Compatibility Ideographs: `\uF900-\uFAFF` (variant forms)
  * **Regex Pattern**: Use `/[\u4E00-\u9FFF\u3400-\u4DBF\uF900-\uFAFF]/g` to match kanji characters
  * **Exclusions**: Hiragana (`\u3040-\u309F`), Katakana (`\u30A0-\u30FF`), Latin, punctuation, and symbols are ignored

* **Text Parsing Service Implementation**:
  * **Service Location**: Create new service at `apps/jp-aid/src/app/services/text-parsing/text-parsing.service.ts`
  * **Interface Definition**: Add `TextParsingResult` interface to `libs/shared-interfaces/src/lib/text-parsing.ts`
  * **Key Methods**:
    * `extractKanji(text: string): string[]` - Returns array of unique kanji in order of first appearance
    * `isKanji(char: string): boolean` - Validates if a single character is kanji
    * `containsKanji(text: string): boolean` - Quick check if text contains any kanji
  * **Angular Patterns**: Use `providedIn: 'root'` for singleton service, signals for any reactive state

* **Data Models & Interfaces** (add to `libs/shared-interfaces`):
  ```typescript
  // libs/shared-interfaces/src/lib/text-parsing.ts
  export interface TextParsingResult {
    originalText: string;
    extractedKanji: string[];
    kanjiCount: number;
    hasKanji: boolean;
  }

  export interface KanjiExtractionOptions {
    preserveOrder?: boolean;      // Default: true - maintain order of first appearance
    removeDuplicates?: boolean;   // Default: true - return only unique kanji
    includeRareKanji?: boolean;   // Default: true - include Extension A kanji
  }
  ```
