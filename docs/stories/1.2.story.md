# Story 1.2: Results Display

**Status:** Review

**Story**
As a learner, I want to see a grid of resulting kanji, with each list item clearly displaying the character and its primary English meaning, so I can quickly identify the one I'm interested in.

**Acceptance Criteria (ACs)**

1. The results are displayed in a responsive grid after a search is initiated.
2. Each item in the grid is a card that displays the kanji character and its primary English meaning.
3. The results grid is sorted and filtered based on the search query.
4. The results grid is paginated for easy navigation.
5. Cards in the grid have distinct hover and active/selected states.

  * Each `mat-card` should have hover and active states to provide visual feedback to the user. [Source: front-end-spec.md#kanji-list-item]

* **Technical Constraints**:
