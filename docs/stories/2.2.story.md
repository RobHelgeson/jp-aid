# Story 2.2: Kanji Ordering

**Status:** Not Started

**Story**
As a user, I want the extracted kanji to be presented in the order they appear in the input, so that the context of the original sentence is preserved.

**Acceptance Criteria (ACs)**

1. The output list of kanji matches the order of appearance in the input.
2. If a kanji appears multiple times, only the first occurrence is kept.
3. The order is preserved when passing data to the results/detail screens.

**Dev Technical Guidance**

* **Previous Story Insights**: Story 2.1 implemented text parsing and kanji extraction functionality. The TextParsingService now supports basic input processing.
* **Kanji Ordering Implementation**:
  * **Order Preservation Logic**: Extend existing services to maintain kanji order during extraction
  * **Duplicate Handling**: Implement logic to track first occurrences only
* **Data Models & Interfaces**:
  * **Order Preservation Interface**: Define interfaces for ordered kanji results
  * **Service Extension**: Add methods to handle ordering and duplicate removal
* **Component Architecture**:
  * **Results Component**: Ensure order is preserved when displaying extracted kanji
  * **Detail Screen Sync**: Maintain proper ordering in detail views

**Tasks / Subtasks**

1. **(AC: 1-3)** Implement order preservation logic
   * [ ] Extend text parsing service with ordering methods
   * [ ] Implement tracking of first occurrences only
   * [ ] Test ordering with various input scenarios

2. **(AC: 1-3)** Integrate with UI components
   * [ ] Ensure results component displays kanji in correct order
   * [ ] Verify detail screen maintains proper ordering
   * [ ] Test integration with different input sequences

3. **(AC: 1-3)** Comprehensive testing implementation
   * [ ] Create unit tests for ordering methods
